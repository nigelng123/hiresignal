# HireSignal

A modern data engineering portfolio project that simulates an enterprise recruitment pipeline.

## Tech Stack

- Python 3.11
- Databricks
- Delta Lake
- dbt
- Faker
- GitHub Actions
- Pytest
- Ruff
- Black

## Project Goals

- Generate synthetic hiring data
- Simulate real-world data quality issues
- Build Bronze, Silver and Gold Delta tables
- Validate data with dbt tests
- Build an AI recruiting analytics agent
